Matt & Stories

MattStories Studio

A private tool its owner uses to plan short videos and publish them to the owner’s own YouTube, Instagram and TikTok accounts.

  • Private · owner only
  • Runs locally in Poland
  • Official APIs only

What it is

  • A local app that runs on the owner’s computer and is reachable only from that computer.
  • It is not offered to the public, not distributed and not sold. No one else can sign up.
  • Test mode is the default. A real post happens only after the owner approves a specific video, platform and time.

Platforms

Connected

YouTube

YouTube Data API v3: uploads approved Shorts and reads their status.

Connected

Instagram

Instagram Graph API: publishes approved Reels at the approved time.

In preparation

TikTok

Login Kit and Content Posting API: waiting for configuration and, if required, verification by TikTok.
